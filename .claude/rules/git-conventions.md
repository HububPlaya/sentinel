# Git & commit conventions

Follow `docs/pr-convention.md` as written: `type(scope): short summary` subject (lowercase,
imperative, no trailing period), blank line, then dash bullets stating what changed and why.
Match the style of recent real commits (`git log`) rather than a generic template.

See `CLAUDE.md`'s "Branch naming" section for the one override that takes precedence over
`docs/pr-convention.md`'s own documented branch form.
